# Design

Sweep owns glob syntax and matching. Its runtime closure is `std`; filesystem
expansion is an optional layer above the pure matching APIs. Ignore-file
precedence, path normalization, filesystem case equivalence and locale rules
belong to callers.

## Layers and ownership

`syntax`, `unit`, `unicode` and the generated `fold` table define how units
compare. `class` owns bracket membership. `program` defines Thompson nodes and
the subject reading shared by a program. `parse` emits those nodes with an
explicit stack for groups; it never recurses or expands numeric intervals into
individual alternatives.

`direct`, `strategy` and `nfa` execute below the one-shot, DFA and hashed-table
layers. `Pattern` owns its compiled program and copied source. `Set` partitions
entries by subject reading, owns immutable strategies and programs, and puts
mutable DFA state in a caller-owned `Cache`. Queries on a shared Pattern need
no shared mutable state; each thread querying a Set owns a separate cache.
`gitignore` parses one line without owning file or precedence policy.

`Walk` borrows its root and matcher, owns traversal state, and accepts Io per
call. Its returned path is borrowed until the next call; `expand` instead
returns owned paths. Walking uses invariant bases and `leadsTo` for pruning,
keeps filesystem or lexical order, and uses resolved ancestor paths to stop
directory-symlink cycles when following links is enabled. I/O failures propagate
except the explicitly skipped missing entries and link loops.

## Matching and bounds

Plain byte patterns run directly from their text. Literal rejection still
validates unread syntax before returning: malformed patterns cannot become
valid merely because a subject mismatches early. A standalone `*/` consumes
one component before the general reader is needed. Within a component, the
reader keeps its end locally while scanning all remaining star segments. This
avoids repeated separator searches without adding cache state to every star
or carrying component bounds through globstar retries.

Other patterns compile to a Thompson NFA. Ordinary epsilon edges point forward
and close in index order. Repeated extglobs emit backward epsilon edges; the
parser marks that fact on the program. Only these programs use visited-context
tracking and rewind the closure scan. Both executors share the instruction
semantics. Each `(node, context)` closes at most once per input position, giving
the asserted O(subject units × NFA states) bound. No executor backtracks or
recurses.

Subject units are folded once per NFA step and compared across all active
threads. Raw units remain available for separators and leading dots: a folding
alias must not become a separator. DFA partition refinement likewise computes
each representative's canonical unit once, then reuses it across predicates.
Ordinary parser loops omit numeric, extglob and capture checks when those
features are disabled; they use the same parser with compile-time selection.

Compiled patterns first use literal strategies, fixed-width star tails or
validated direct execution. General patterns use a bounded eager DFA with NFA
fallback. Sets hash exact paths, basenames, extensions, path/component prefixes
and suffixes, then use a bounded lazy DFA for the remaining entries. A single
plain remaining entry can run directly; its program is retained for ancestor
and pruning queries. Cache exhaustion clears DFA states, then falls back to the
NFA when a query keeps clearing. The matching engine allocates nothing after
cache setup; `Set.all` may grow the caller's output list.

## Dialects and optional features

Syntax fields are independent; presets supply common combinations. Extglob
supports regular `?()`, `*()`, `+()` and `@()` groups, including nesting and empty
alternatives. Complement groups are refused. The editorconfig preset adds
basename/root anchoring, literal brace rules and signed 64-bit intervals with
canonical decimal spellings and optional signs. Intervals compile into digit
blocks instead of enumerating their values.

Unicode folding uses the committed Unicode 18.0.0 C/S mappings generated by
`tools/casefold.zig`. The table has 1,533 nonidentity mappings and needs neither
a runtime dependency nor a consumer build generator. It performs default simple
folding; full folding, Turkic folding and normalization are excluded. Invalid
UTF-8 bytes remain distinct units.

Captures build a separate tagged program on demand. The caller owns reusable
capture scratch, with one cache per concurrent query. Ordered Pike execution
chooses the first successful alternative and greedy repetitions. Captures use
byte offsets; unselected captures are null, and participating empty captures
have equal endpoints. Ordinary matches carry no tags or capture histories.
Capture scratch is O(states × captures), and copying histories adds O(captures)
work per visited state.

## Validation

Correctness gates compare engines, dialect oracles, committed vectors and
Unicode records. Shakedown supplies generators, allocation-failure checks and
I/O faults. Deterministic tests enforce the step bound, no query allocations,
closure mode and resource cleanup. Timing stays in the public `bench/` workloads
and manual interleaved ReleaseFast comparisons; CI compiles benchmarks without
using timings as a gate.


## Composed scalar matching

`Options.normalization` defaults to `exact`. `nfc` makes pattern literals
and subject units canonical NFC scalars. Only the parser transforms literal
runs and bracket members; syntax and wildcard boundaries remain intact.
Ranges and negation act on composed scalar values. A bracket member whose
canonical segment still has multiple scalars is InvalidPattern, diagnosed
as multi_scalar_member. `?` consumes one composed scalar, not a grapheme.

Sweep owns Unicode 18 folding and composition data, generated by
`tools/casefold.zig` and `tools/normalize.zig`. Composition includes full
canonical decomposition, canonical ordering, composition exclusions and
algorithmic Hangul. Malformed UTF-8 bytes remain distinct segment barriers.
`Composed` exposes the same allocation-free iterator to callers.

Ordering uses a 256-class bitset and at most 255 stable scans per segment,
so arbitrary combining runs require constant scratch and O(n) work.
No stream-safe truncation or combining-length cap changes the language.
The automata keep their O(n*m) worst-case bound. Capture offsets retain
original byte boundaries; reordered outputs share their segment end.
Exact matching retains its existing hot loops; ASCII NFC takes those loops
after an ASCII check. Literal byte strategies are disabled for NFC.

Filesystem callers own measured root and directory identity policy and
canonical kernel spelling. Unicode default simple folding does not establish
the identity rules of a filesystem. `alternate_separator` is parsed by sweep
and gives native paths a second separator spelling without text rewriting.

The public cut is still work in progress; this seam does not establish
release or full-family graduation.
